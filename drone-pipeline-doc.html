CV-RL Autonomous Drone Pipeline — Technical Documentation

Technical details of the Teleop → Behaviour Cloning → PPO pipeline for autonomous quadrotor navigation in NVIDIA Isaac Sim.

1. Environment Architecture

The custom Gymnasium environment wraps NVIDIA Isaac Sim + OmniDrones to provide a standard RL interface:

import gymnasium as gym
from omni.isaac.kit import SimulationApp

class DroneNavEnv(gym.Env):
    """Custom Gymnasium environment for quadrotor navigation."""
    
    def __init__(self, config):
        super().__init__()
        self.observation_space = gym.spaces.Box(
            low=-np.inf, high=np.inf, 
            shape=(obs_dim,), dtype=np.float32
        )
        self.action_space = gym.spaces.Box(
            low=-1.0, high=1.0, 
            shape=(4,), dtype=np.float32  # thrust + 3-axis torque
        )
        self.max_episode_steps = 1000
        self.collision_threshold = 0.3  # metres
    
    def reset(self, seed=None):
        # Randomize obstacle positions for domain randomization
        self._randomize_obstacles()
        # Reset drone to random start position
        self._reset_drone()
        return self._get_obs(), {}
    
    def step(self, action):
        self._apply_action(action)
        self.sim.step()
        
        obs = self._get_obs()
        reward = self._compute_reward()
        terminated = self._check_collision()
        truncated = self.step_count >= self.max_episode_steps
        
        return obs, reward, terminated, truncated, {}

Observation Space

  • Position: (x, y, z) in world frame
  • Velocity: (vx, vy, vz) linear velocity
  • Orientation: quaternion (qw, qx, qy, qz)
  • Angular velocity: (wx, wy, wz)
  • Obstacle distances: raycast readings to nearby obstacles

Action Space

Continuous 4D action: collective thrust + 3-axis torque commands, normalized to [-1, 1].

2. Stage 1 — Teleoperation & Data Collection

Expert demonstrations are collected via keyboard/gamepad teleoperation. Each trajectory is stored as a sequence of (observation, action) pairs:

class DemoCollector:
    def __init__(self, env):
        self.env = env
        self.demonstrations = []
    
    def collect_episode(self):
        obs, _ = self.env.reset()
        trajectory = []
        
        while True:
            action = self._get_teleop_input()
            next_obs, reward, term, trunc, info = self.env.step(action)
            trajectory.append({
                'obs': obs, 'action': action,
                'reward': reward, 'next_obs': next_obs
            })
            obs = next_obs
            if term or trunc:
                break
        
        self.demonstrations.append(trajectory)

3. Stage 2 — Behaviour Cloning

The collected demonstrations train an initial policy via supervised learning (imitation):

from torch.utils.data import DataLoader

# Dataset: (observation, expert_action) pairs
dataset = DemoDataset(demonstrations)
loader = DataLoader(dataset, batch_size=64, shuffle=True)

policy = PolicyNetwork(obs_dim, action_dim)
optimizer = torch.optim.Adam(policy.parameters(), lr=3e-4)

for epoch in range(num_epochs):
    for obs_batch, action_batch in loader:
        pred_actions = policy(obs_batch)
        loss = F.mse_loss(pred_actions, action_batch)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

This produces a warm-start policy that demonstrates basic navigation competence, providing a much better starting point than random initialization for the RL phase.

4. Stage 3 — PPO Fine-Tuning

The behaviour-cloned policy is loaded into Stable-Baselines3 and fine-tuned using PPO:

Reward Function

def _compute_reward(self):
    # Progress toward goal
    dist_to_goal = np.linalg.norm(self.drone_pos - self.goal_pos)
    progress_reward = self.prev_dist - dist_to_goal
    
    # Collision penalty
    collision_penalty = -10.0 if self._check_collision() else 0.0
    
    # Efficiency bonus (penalize excessive energy use)
    energy_penalty = -0.01 * np.sum(np.abs(self.current_action))
    
    # Goal reached bonus
    goal_bonus = 100.0 if dist_to_goal < 0.5 else 0.0
    
    self.prev_dist = dist_to_goal
    return progress_reward + collision_penalty + energy_penalty + goal_bonus

5. Domain Randomization

To improve generalization, obstacles are randomized each episode:

  • Position: Uniform sampling within arena bounds
  • Size: Varying obstacle dimensions
  • Count: Variable number of obstacles per episode
  • Drone start/goal: Randomized to prevent overfitting to fixed configurations
