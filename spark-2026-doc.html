SPARK Challenge 2026 — Technical Documentation

Technical details of the event-based spacecraft pose estimation pipeline developed for the SPARK Challenge 2026 (AI4Space @ CVPR 2026, Stream 2).

1. Event Camera Data & the SPADES Dataset

Unlike conventional frame-based cameras, event cameras (neuromorphic sensors) output asynchronous per-pixel brightness changes. Each event is a tuple (x, y, t, p) representing the pixel coordinate, timestamp, and polarity (positive or negative change).

The SPADES dataset provides event streams of a spacecraft model under varied lighting and motion profiles, split into Synthetic and Real partitions. Each sample has ground-truth 6-DoF pose labels (position + quaternion orientation).

2. Voxel-Grid Encoding

Raw event streams are converted into a fixed-size tensor representation using voxel-grid encoding:

# Voxel-grid parameters
num_temporal_bins = 5    # Temporal resolution
num_polarities   = 2    # Positive & negative events
# Output: tensor of shape [C=10, H, W]
# where C = num_temporal_bins × num_polarities

def events_to_voxel_grid(events, H, W, num_bins=5):
    """Convert event stream to voxel grid tensor."""
    voxel_grid = np.zeros((2 * num_bins, H, W), dtype=np.float32)
    
    t_start, t_end = events['t'].min(), events['t'].max()
    t_norm = (events['t'] - t_start) / (t_end - t_start + 1e-6)
    
    for i in range(len(events)):
        x, y = events['x'][i], events['y'][i]
        p = events['p'][i]  # 0 or 1
        bin_idx = int(t_norm[i] * num_bins)
        bin_idx = min(bin_idx, num_bins - 1)
        channel = p * num_bins + bin_idx
        voxel_grid[channel, y, x] += 1.0
    
    return voxel_grid

This encoding preserves both spatial structure (where events occurred) and temporal dynamics (when events occurred within the time window), producing a 10-channel image-like tensor suitable for CNN processing.

3. Model Architecture

The network follows a ResNet-style architecture adapted for 10-channel voxel-grid input:

class SpacecraftPoseNet(nn.Module):
    def __init__(self, num_input_channels=10):
        super().__init__()
        # Modified ResNet backbone for 10-channel input
        self.backbone = models.resnet34(pretrained=False)
        self.backbone.conv1 = nn.Conv2d(
            num_input_channels, 64,
            kernel_size=7, stride=2, padding=3, bias=False
        )
        num_features = self.backbone.fc.in_features
        self.backbone.fc = nn.Identity()
        
        # Pose regression heads
        self.translation_head = nn.Linear(num_features, 3)   # (tx, ty, tz)
        self.rotation_head = nn.Linear(num_features, 4)      # quaternion (qw, qx, qy, qz)
    
    def forward(self, x):
        features = self.backbone(x)
        t = self.translation_head(features)
        q = self.rotation_head(features)
        q = F.normalize(q, dim=-1)  # Unit quaternion constraint
        return t, q

4. Loss Functions

Geodesic Loss on SO(3)

For rotation estimation, standard L2 loss on quaternions does not respect the geometry of the rotation manifold. Instead, we use the geodesic distance on SO(3):

def geodesic_loss(q_pred, q_gt):
    """
    Geodesic loss on SO(3) via quaternion inner product.
    L = arccos(|<q_pred, q_gt>|)
    """
    # Ensure unit quaternions
    q_pred = F.normalize(q_pred, dim=-1)
    q_gt = F.normalize(q_gt, dim=-1)
    
    # Inner product (absolute value handles double-cover)
    dot = torch.abs(torch.sum(q_pred * q_gt, dim=-1))
    dot = torch.clamp(dot, -1.0 + 1e-7, 1.0 - 1e-7)
    
    return torch.mean(torch.acos(dot))

This loss measures the angle of the shortest rotation between predicted and ground-truth orientations, providing a geometrically meaningful gradient signal.

translation_loss = F.mse_loss(t_pred, t_gt)
